Énfasis y copy multilínea

.ubits-alert__text usa display: flex. Si el mensaje tiene varios hijos directos (texto suelto + <strong>, <p>, etc.), cada hijo se alinea como ítem flex y el copy se “parte” en columnas.

  • Énfasis parcial: <span class="ubits-alert__emphasis">…</span> (inline, font-weight 600).
  • Mensaje largo o HTML: añade ubits-alert--block-text al root (o blockText: true en showAlert).
  • React: prop textBlock en UbitsAlert.

Prompts útiles

Crear alert de notificación

En [ubicación], usa showAlert('[success|info|warning|error|ia|invert|neutral]', '<strong>[título]</strong> [mensaje]', { containerId: '[id]', noClose: true, actionsHtml: '[botones opcionales]' }). Incluye alert.css + alert.js + button.css.

Mensaje de usuario con avatar

En [ubicación], usa showAlert('neutral', '[copy HTML]', { containerId: '[id]', noClose: true, blockText: true, leadingHtml: renderAvatar({ nombre: '[nombre]', avatar: '[url]' }, { size: 'sm' }), actionsHtml: '[botones xs]' }). No reimplementes el markup a mano.

Stack de alertas

En [ubicación], usa showAlertStack('[id]', [{ type: 'success', message: '[msg1]' }, { type: 'warning', message: '[msg2]', options: { actionsHtml: '[botón]' } }], 'sm').
