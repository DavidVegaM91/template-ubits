Prompts útiles

Copia y pega estos textos en Cursor AI. Reemplaza lo que está entre [corchetes] con tu información. Usa renderAvatar, renderAvatarLabel, renderAvatarSocialProof o renderProfileList según la variante.

Avatar único

En [ubicación], usa renderAvatar({ nombre: '[nombre]', avatar: '[url]' }, { size: '[xs|sm|md|lg|xl]', shape: '[circle|rounded]', status: '[online|away|busy|offline]', statusPosition: 'bottom-right', ring: [true|'pulse'|'spin'|'gradient'], badgeIcon: 'far fa-check', fallbackTone: '[muted|brand|solid]' }). Incluye avatar.css + avatar.js.

Con nombre / Prueba social

En [ubicación], usa renderAvatarLabel(persona, { title: '[nombre]', description: '[rol · estado]', size: 'md', status: 'online' }) o renderAvatarSocialProof(personas, { label: '[texto]', size: 'sm', maxVisible: 4, initialsOnly: false }). No reimplementes el markup a mano.

Lista de perfiles

En [ubicación], usa renderProfileList(personas, { size: '[xs|sm|md|lg|xl]', maxVisible: 3, showTooltip: true, hoverSpread: false, hoverLift: false, selectable: false, overflowMode: 'count' }). Después llama wireProfileLists('[selector]') si hay tooltips. Solo avatar.js; no reimplementes popover ni tooltips a mano.
